Nakama bundled offline speech recognition

This directory accompanies the ASR-only Android recognition runtime and model.
The original license and notice texts below are copied without alteration.
SOURCES.json records their source locations, versions, byte counts and SHA-256.
Nakama's own source remains under its existing license; the third-party terms
apply to their respective components.

RUNTIME AND LOCAL MODIFICATIONS
Sherpa-ONNX 1.13.8, copyright its upstream contributors, Apache-2.0.
https://github.com/k2-fsa/sherpa-onnx/tree/v1.13.8
See SHERPA-ONNX-LICENSE.txt.
Nakama builds the JNI library from pinned upstream source for arm64-v8a and
x86_64, with TTS, speaker diarization and the C API disabled. The upstream AAR
provides Kotlin classes/resources; its original native libraries are replaced.
The packaged native libraries are libsherpa-onnx-jni.so and libonnxruntime.so.
No native espeak/piper text-to-speech component, Vosk or JNA is included by this
speech runtime. Spoken replies use a separately installed Android TTS engine.
The reproducible build recipe is scripts/build-bundled-speech-runtime.py.

ONNX Runtime 1.28.2, copyright Microsoft Corporation, MIT.
https://github.com/microsoft/onnxruntime/tree/v1.28.2
See ONNXRUNTIME-LICENSE.txt and ONNXRUNTIME-ThirdPartyNotices.txt.
The pinned Android binary is published by the Sherpa project contributor at:
https://github.com/csukuangfj/onnxruntime-libs/releases/tag/v1.28.2
Its exact archive hash is recorded in the runtime build recipe/provenance.
The upstream aggregate third-party notice is retained in full; it covers
upstream build variants and does not assert that every listed backend ships here.

ANDROID C++ RUNTIME
Android NDK 28.2.13676358 (r28c), with ANDROID_STL=c++_static, supplies the
statically linked libc++/libc++abi runtime and supporting compiler runtime.
Full exact NDK NOTICE and NOTICE.toolchain files are retained as
ANDROID-NDK-NOTICE.txt and ANDROID-NDK-NOTICE.toolchain.txt. These include the
LLVM/Apache exceptions and C++ runtime notices as supplied with that NDK.
They are aggregate toolchain notices and do not mean the whole NDK is shipped.

ENGLISH SPEECH MODEL
sherpa-onnx-streaming-zipformer-en-2023-06-26
Publisher: csukuangfj / the Sherpa-ONNX model project.
Pinned revision: 672fbf1b30579d6585301139bb363f42a0ad4a24
https://huggingface.co/csukuangfj/sherpa-onnx-streaming-zipformer-en-2023-06-26/tree/672fbf1b30579d6585301139bb363f42a0ad4a24
The model publisher identifies Apache-2.0 in its exact MODEL-README.md;
the full license is included as APACHE-2.0.txt. Model weights and tokens are
packaged from the pinned files without modification. Nakama derives a text BPE
vocabulary from the publisher's bpe.model and adds a Nakama hotword hint;
see BPE-VOCABULARY-PROVENANCE.md for the source and output hashes.
Nakama additionally provides local microphone lifecycle, strict wake routing,
signal evidence checks and model-integrity verification. Audio is not recorded
and model preparation uses APK assets without a runtime model download.
